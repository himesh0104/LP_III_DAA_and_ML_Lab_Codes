# SPPU LP-III: DAA & Machine Learning Lab Codes and Viva Preparation

This repository contains the verified code, manual terminal demo data, and viva preparation materials for **Laboratory Practice - III (LP-III)** for Savitribai Phule Pune University (SPPU).

## 📁 Repository Structure
- **LP_III_DAA_and_ML_Lab_Codes/**: Standalone Python scripts (.py) and Word documentation (.docx) for all 10 DAA and ML practicals, along with datasets and test runners.
  - **DAA/**: Practicals 1 to 5 (Fibonacci, Huffman, Fractional Knapsack, 0/1 Knapsack, N-Queens)
  - **ML/**: Practicals 1 to 5 (Uber Fare, Email Spam, Customer Churn, Diabetes, Sales Clustering)
- **LAB VIVA PREPARATION – NOVEMBER 2026/**: Comprehensive viva questions, algorithms, and practical exam guides.
